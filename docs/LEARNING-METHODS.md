# 学习方法引擎

本项目采用“多方法协同”，而不是迷信单一学习法。不同方法解决不同瓶颈。

## 核心方法

### 1. 主动回忆（Active Recall）
优先从记忆中提取答案，而不是重复阅读。适合税率、期限、定义、构成要件、征税范围和规则边界。

### 2. FSRS / 间隔重复
根据个人记忆状态动态安排复习，不机械使用固定 1/2/4/7 天表。系统记录稳定度、难度、最后复习时间和预测遗忘风险。

### 3. 费曼学习法
要求学习者用自己的话解释规则。系统检查是否遗漏主体、客体、税基、税率、时间、凭证、例外、优惠、计算顺序等关键要素。

### 4. 第一性原理
把复杂税务问题拆到底层：
`征税目的 → 纳税主体 → 征税对象 → 税基 → 税率 → 纳税义务发生 → 扣除/抵扣 → 优惠 → 申报管理 → 例外`
再从底层规则重新组合成复杂案例。

### 5. 交错学习（Interleaving）
把容易混淆的规则混合训练，例如不同税率、不同所得类型、一般计税与简易计税、视同销售与非应税行为。

### 6. 刻意练习
只重复“刚好超过当前水平”的任务，针对具体薄弱点，不追求无目的刷题量。

### 7. 认知负荷控制
复杂材料题先拆成小步骤；如果连续失败，自动退回前置知识，避免难度超过可学习区。

### 8. 精细加工与自我解释
每条规则不仅问“是什么”，还问“为什么”“什么时候不适用”“和哪个规则最容易混”。

### 9. 具体实例与反例
每个抽象规则至少配置典型例、边界例和反例。

### 10. 双重编码
将文字、公式、流程图、表格和结构图组合，特别适合计税流程、税率表和纳税义务发生时间。

### 11. 生成效应
先让学习者尝试生成答案、计算式或解释，再展示标准答案。

### 12. 苏格拉底追问
AI 不立即给答案，而按“依据是什么→条件是什么→有无例外→如果条件改变会怎样”逐步追问。

### 13. 错误驱动学习
错误分类至少包括：规则错误、税率错误、税基错误、时间错误、抵扣错误、优惠错误、阅读错误、计算错误、跨税种混淆。

### 14. 元认知校准
每次答题同时记录“我有多确定”。重点识别“高自信但答错”的危险知识点。

### 15. 迁移训练
同一规则从定义题→单选→多选→小计算→材料题→跨章节综合题逐级迁移。

## 学习边界探测

系统动态估计：
- MASTERY：已经稳定掌握；
- GROWTH_ZONE：稍加努力可答出，优先训练；
- OVERLOAD：明显超出当前能力，需拆解前置知识。

目标不是把所有内容做得更难，而是最大化处在 GROWTH_ZONE 的有效学习时间。

## 税法的特殊策略

税法内容具有高时效性、高例外密度、高数字密度和高相似规则干扰。学习引擎必须把“年度版本”作为一等属性，旧题不能简单删除，而应标注其适用政策版本并与当前规则对比。
