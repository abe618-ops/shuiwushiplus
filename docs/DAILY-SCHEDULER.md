# 每日学习调度器

目标：把一天中不同精力状态用于不同类型的税务师学习任务，并由掌握度与遗忘风险动态调整。

## 默认四时段

### 清晨 / 晨跑间隙（约 5–15 分钟）
低认知负荷、可语音化：
- 税率/扣除率/期限快速回忆
- 高频定义
- 是非辨析
- 关键词卡片
- 语音问答
- 昨日最危险的 3–5 个遗忘点

### 上午（约 20–45 分钟）
理解与结构化：
- 新知识点
- 第一性原理拆解
- 规则—条件—例外
- 知识图谱连接
- 典型例与反例
- 小规模主动回忆

### 中午（约 10–25 分钟）
检索与辨析：
- 单选/多选
- 易混规则交错练习
- 到期 FSRS 卡片
- 昨日错题
- 高自信错误复测

### 晚上（约 30–60 分钟）
执行与迁移：
- 计算题
- 材料题
- 跨章节/跨税种综合题
- 费曼复述
- 苏格拉底追问
- 错因复盘与下一轮计划

## 动态调度变量

每个知识点至少维护：
- mastery：掌握度
- stability：记忆稳定度
- difficulty：个体难度
- forgettingRisk：遗忘风险
- confidenceCalibration：置信度校准
- errorTags：历史错因
- lastSeenAt：最近学习时间
- dueAt：下次应复习时间
- prerequisiteGap：前置知识缺口

## 任务优先级

建议优先级函数：

`priority = 遗忘风险 + 考试权重 + 错题严重度 + 前置价值 + 近期政策变化权重 - 已稳定掌握惩罚`

实际实现时再经过时间预算和认知负荷约束。

## 三时段兼容模式

如果用户只需要上午/中午/晚上三次推送，则把清晨内容合并进上午第一段；如果允许四次，则清晨保持独立。

## 推送内容不是固定题量

每天可以显示：
- 今日总预计时长
- 必须完成
- 建议完成
- 可选强化
- 到期复习数量
- 高风险遗忘数量
- 新知识数量

系统目标是在时间有限时优先保住高价值知识，而不是为了“完成计划”机械刷题。
