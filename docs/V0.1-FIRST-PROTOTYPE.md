# 税务师学习+ V0.1 第一版原型

## 目标

V0.1 不是最终题库，而是用于验证“学习任务调度 + 题目作答 + 解析反馈 + 学习方法嵌入”的最小可运行版本。

## 当前能力

- 科目切换：税法一 / 税法二 / 全部。
- 四时段学习：清晨记忆、上午理解、中午主动回忆、晚间综合训练。
- 学习任务自动生成。
- 选择题作答、即时判定、解析展示。
- 题目明确区分来源，当前样题均为原创仿真题。
- 手机端响应式布局。
- 学习方法展示：第一性原理、主动回忆、费曼法、间隔重复、交错训练、错因追踪。

## 官方范围依据

当前第一版内容范围参照中国注册税务师协会发布的 2025 年度税务师职业资格考试大纲。税法（一）官方大纲将要求分为“了解、熟悉、掌握”三个层级，V0.1 后续会把这一层级映射到题目难度和任务调度。

税法（一）重点包括税法基本原理、增值税、消费税、城市维护建设税、土地增值税、资源税、车辆购置税、环境保护税、烟叶税、关税和非税收入等。

## V0.2 计划

1. 将题目从 app.js 拆为独立 JSON 数据文件。
2. 建立税法一、税法二完整章节树。
3. 引入 LocalStorage 保存学习进度、错题和掌握度。
4. 增加多选题、计算题、材料题。
5. 增加题目来源核验字段和法规版本字段。
6. 加入简化 FSRS 调度器。
7. 增加“费曼模式”：用户先自行解释，再查看系统标准结构。
8. 建立联网采题/政策更新适配层，但对商业题库内容不进行未经许可的批量复制。
9. 准备 PWA 与 Android WebView/原生迁移。

## 运行

直接打开 `web/index.html` 即可运行；若浏览器安全策略限制本地资源，也可用任意静态 HTTP Server 托管 `web/` 目录。
