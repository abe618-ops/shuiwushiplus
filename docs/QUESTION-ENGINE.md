# 题目引擎设计

题目是“税务师学习+”的核心训练载体，但系统不以题量为唯一目标，而以题目的真实性、可核验性、时效性、诊断价值和迁移价值为核心。

## 题目流水线

`联网发现 → 来源识别 → 抓取/摘要 → 去重 → 政策版本识别 → 法规核验 → 答案验证 → 解析生成 → 难度与知识点标注 → 入库 → 个性化投放`

## 来源等级

- A：官方公开题、公开样题、考试大纲示例、官方法规案例。
- B：允许使用或合理摘要的可靠学习资料。
- C：依据有效规则原创的仿真题。
- D：AI 生成的动态变式题。

必须保留 provenance（来源链）。C/D 类不得标记为“真题”。

## 题型

- 单项选择
- 多项选择
- 判断式概念辨析
- 小型计算题
- 连续计算题
- 材料分析题
- 跨章节综合题
- 跨税种综合题
- 错题变式题
- 反事实题：改变一个条件后重新判断
- 口述题：要求解释而不是选择

## 解析标准

高质量解析至少包含：
1. 正确答案；
2. 解题路径；
3. 关键规则；
4. 适用条件；
5. 例外；
6. 计算过程；
7. 错误选项为何错误；
8. 易错点；
9. 法律/政策依据；
10. 政策适用年度；
11. 关联知识；
12. 可生成的下一道变式题。

## 校验策略

AI 不作为单一事实源。对于税率、扣除率、期限、优惠条件、纳税义务发生时间等高风险字段，应优先基于官方法规/公告/考试大纲进行规则校验。

题目状态：
- `discovered`
- `parsed`
- `rule_checked`
- `answer_checked`
- `ready`
- `deprecated`
- `needs_review`

## 个性化出题

建议每日任务不是随机刷题，而是组合：
- 新知识题
- 到期复习题
- 高遗忘风险题
- 错题变式
- 相似规则辨析
- 跨章节迁移
- 综合材料题

系统根据正确率、答题时间、置信度、连续错误类型与 FSRS 状态调整下一题。
