# 税务师学习+（shuiwushiplus）

面向税务师职业资格考试的开放式、自适应学习项目。项目目标不是做一个普通题库，而是把学习科学、税法知识结构、题目生成/校验、个人遗忘曲线和多时段学习任务结合起来，逐步发展为 Web + Android APK。

## 核心目标

1. 覆盖税法（一）、税法（二）、涉税服务实务、财务与会计、涉税服务相关法律。
2. 以官方大纲、法律法规和可核验资料为知识底座，建立版本化知识库。
3. 支持单选、多选、计算题、材料题、综合题、错题变式与跨章节训练。
4. 通过 FSRS/间隔重复、主动回忆、费曼学习法、第一性原理、交错学习、刻意练习、认知负荷控制、双重编码、生成效应、苏格拉底追问、元认知校准等方法提高学习效率。
5. 将每日学习拆成清晨、上午、中午、晚上等不同认知负荷时段，自动生成适合当时状态的任务。
6. 建立联网题目采集、来源标注、规则核验、答案验证、解析生成和版权合规机制。
7. 最终形成“税务师学习+”Android APK，并保留 Web/桌面端能力。

## 学习引擎

学习流程：

`知识输入 → 闭卷主动回忆 → 题目检验 → 错因识别 → 费曼复述 → 第一性原理拆解 → 相似规则交错辨析 → 变式题 → FSRS 间隔复习 → 跨章节迁移`

系统持续估计三类区域：

- 已稳定掌握：降低重复频率。
- 稍加努力可答出：核心训练区，优先投入时间。
- 完全不会/认知过载：先拆前置知识，降低一次性难度。

## 科目模块

- `subjects/tax-law-1/`：税法（一）
- `subjects/tax-law-2/`：税法（二）
- `subjects/tax-service-practice/`：涉税服务实务
- `subjects/finance-accounting/`：财务与会计
- `subjects/tax-related-law/`：涉税服务相关法律

## 每日学习节奏

- 清晨/晨跑：低负荷记忆，税率、期限、征税范围、关键词、语音问答。
- 上午：新知识与理解，第一性原理拆解规则、边界、例外。
- 中午：主动回忆，单选、多选、易混辨析、昨日错题。
- 晚上：执行与迁移，计算题、材料题、综合题、费曼复述和错因复盘。

后续由个人掌握度、遗忘风险和剩余时间动态调整，不固定平均分配。

## 题目可信度原则

题目来源分级：

- A：公开且可核验的官方/历史公开题目或样题。
- B：经授权、允许引用或仅作合理摘要的可靠学习资料。
- C：依据有效法律法规原创的仿真题。
- D：AI 动态生成的变式题。

C/D 类必须明确标注“原创仿真题/AI 变式题”，不得冒充历年真题。所有进入正式题库的题目应尽量保留政策年度、规则生效日期、来源、答案、解析、法条依据和校验状态。

## 第一阶段

当前先建设 V0：知识架构、学习方法框架、题目数据结构、科目模块、每日调度和联网题目处理规范。随后进入 V1 可运行原型，再进入 Android APK。

## 项目定位

本项目用于学习、研究与软件开发，不提供税务、法律或投资意见。税收规则具有时效性，题目和解析应标注适用年度，并优先核对官方最新有效规定。
