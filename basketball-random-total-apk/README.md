# 篮球随机数大小盘 APK v1.0

一个离线 Android 小工具：随机生成或手工输入数字，按当前实验规则对篮球全场总分“大 / 小”进行合参判断。

## 当前规则

- 奇偶结构：奇数偏放量，偶数偏收缩；
- 数字和奇偶；
- 数字走势：连续上升 / 连续下降 / 高位重复；
- 高位数 7、8、9 与收口数 4、6；
- 尾数强化；
- 0/9 相邻的波动放量；
- 0、6、9 共现；
- 多 7 的高位持续性；
- 基于合参权重生成“实验总分中枢”和核心区间；
- 可输入实际大小盘口，自动比较中枢与盘口。

规则回归示例：`096 → 偏大`、`764 → 偏小`、`277 → 偏大`、`609 → 偏大`；其中当前对话已确认 `096` 的大分方向命中，其余仅作为算法示例，等待后续样本继续校准。

> 仅用于随机数方法实验与娱乐，不代表统计学真实胜率或投注建议。
