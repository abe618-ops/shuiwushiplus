# 梅花足球盲测 APK

一个离线 Android 原型，用于把当前聊天中形成的「梅花足球盲测 v1.3」做成可重复、可冻结、可复盘的随机数实验工具。

## 当前版本

- App：1.0.0
- 算法协议：v1.3 双轨盲测
- 包名：`com.abe618.meihuafootball`
- 最低 Android：8.0（API 26）
- Target SDK：35
- 无联网权限，全部计算和历史记录在本机完成

## 核心流程

1. 输入主队/客队名称（仅作记录，不参与随机计算）。
2. 点击「完全随机」生成 `000-999` 三位数，或手工输入三位数。
3. 第一位定上卦、第二位定下卦，三位数字之和定动爻。
4. 自动计算本卦、互卦、变卦和五行生克路径。
5. A轨先输出无方向比赛形态：平/胜负、大小、单双、总进球、双方进球、零封、净胜球、比分形态。
6. B轨同时保留两种主客极性映射：
   - B1：下卦=主队，上卦=客队；
   - B2：动爻定体用，体视为主队、用视为客队。
7. B1/B2冲突时不事后择优，直接标记「主客极性争议」，优先看A轨。
8. 点击「冻结本场」生成冻结标记并保存。
9. 赛后输入实际比分，应用按冻结结果逐项复盘，并单独识别镜像比分（如 `1:0 → 0:1`）。

## 三位数起卦

八卦映射：

| 数值 | 卦 | 五行 |
|---|---|---|
| 1 | 乾 | 金 |
| 2 | 兑 | 金 |
| 3 | 离 | 火 |
| 4 | 震 | 木 |
| 5 | 巽 | 木 |
| 6 | 坎 | 水 |
| 7 | 艮 | 土 |
| 8 | 坤 | 土 |

- `9 mod 8 = 1`，所以 9 取乾；
- 余 0 作 8，所以 0 取坤；
- 动爻 = `(A+B+C) mod 6`，余0作第6爻。

## v1.3 关键纪律

- 先预测、后看赛果；
- 一经冻结，不赛后换主客/体用/解释；
- 镜像比分只算结构命中，不算精确命中；
- 「比和」只表示没有新的反转力量，不自动等于平局；
- A→B→A 来回结构降低胜负置信度并防平；
- 礼法信息不足时自动记为 `G=0`，不参与修正；
- 当前 APK 的礼法层默认弃权，因为纯随机盲测没有完整的时令、藏象节律、现场外应等信息；
- 本工具用于实验研究，不声明梅花易数具有科学预测效力，也不提供投注保证。

## 构建

GitHub Actions 工作流：`.github/workflows/build-meihua-football-random.yml`

也可以本地使用 Gradle 8.9 + JDK 17：

```bash
cd projects/meihua-football-random
gradle :app:assembleDebug
```

APK：

```text
app/build/outputs/apk/debug/app-debug.apk
```

Debug APK 已由 Android Gradle Plugin 使用调试签名签署，可以直接安装测试。
