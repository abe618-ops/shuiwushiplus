# 六壬足球双盘 Android

一个用于规则研究、盲测与复盘的 Android 工具。核心功能：

- **740 局随机日期盘**：固定 `seed=740` 生成 740 个日期/时辰样本，每次用 `SecureRandom` 抽一局；可手工输入 0-739 局号复现。
- **今日活时盘**：当天日干支 + 手机当前时辰；月将按中气近似表自动取值，临界日允许手工覆写。
- **大六壬排盘**：月将加时、四课、九宗门、十二天将、神煞基础项；已用规则资料中的 5 个手工例自检三传。
- **主客定位投票**：D0 干客支主 + 球队成立年支 + 教练生年支；不上四课或冲突则弃权。
- **三池评分**：主/平/客，按月令旺衰、生克、三传、天将、勾玄、禄德、驿马、运移、课体、合冲加权后 softmax。
- **联网赛程**：优先合并 ESPN 常见足球联赛公开 scoreboard；无数据时回退 TheSportsDB v1 免费赛程接口。
- **球队成立年补全**：按球队名称查询 TheSportsDB；教练出生年保留手工输入，避免伪造。
- **年命独立占测**：不填写球队名，一个输入框按“前主后客”输入两个年份/生肖/地支，双盘并行。

## 规则口径

项目依据会话提供的三份研究资料移植：

1. `01_研究资料与主客定位来源.md`
2. `02_排盘规则.md`
3. `03_主客定位与评分模型.md`

### 自检例

- 甲子日 子将子时：伏吟 → 寅巳申
- 甲子日 午将子时：返吟涉害 → 寅申寅
- 辛丑日 巳将寅时：别责 → 酉丑丑
- 丁未日 丑将未时：返吟无克 → 丑未丑
- 庚申日 丑将子时：八专 → 亥子丑

## 说明

该工具用于规则复盘/研究与盲测，不保证对真实比赛有预测能力，不构成投注建议。
