# Football Prediction V2 / 足球竞技预测统一研究框架

版本日期：2026-09-05

目标：把近期 Work/文件库、聊天记录与既有 football skills 中形成的赔率、统计、基本面、术数、随机盘和复盘方法统一为可盲测、可复演、可持续迭代的研究框架。

## 1. 总体原则

- 赛前冻结：任何预测必须在开赛前写入时间戳、输入数据、模型版本与输出，赛后只追加结果和复盘，禁止覆盖原预测。
- 概率优先：市场和统计层输出完整概率，不只给 Top1。
- 同一比分矩阵：胜平负、让球、大小球、总进球、单双、Top 比分尽量由同一概率结构派生，避免互相矛盾。
- 术数隔离：所有术数和随机盘先作为影子实验层，独立记分，初始不影响主模型。
- 防止信息泄漏：只使用预测时刻之前可获得的信息，回测采用 walk-forward。
- 真实盲测优先：不能用精选案例、赛后补解释或删掉失败样本证明模型有效。

## 2. 统一架构：M + S + F + Z + C

### M — Market / 赔率市场层

输入：
- 澳门、香港马会、12BET、立博、Bet365、威廉、Crown 等重点公司；
- 百家平均；
- 1X2、亚洲让球、大小球；
- Betfair 等交易市场（有足够流动性时）；
- T-48h / T-24h / T-6h / T-90m / T-30m / T-10m 快照。

处理：
- 比例去水 + Power/Shin 稳健性比较；
- 加权市场共识，避免把低返还率原始赔率直接横比；
- 公司离散度、变化速度、同步性、反向变化；
- 欧赔—亚盘—大小球的一致/背离；
- “凯利指数”只作为相对市场偏离/赔付暴露特征，不使用“最低凯利必出”等单变量规则。

盘型标签只做可检验定义：
- 顺分布：实力/xG、去水欧赔、亚盘和盘口路径同向；
- 逆分布：名气/基本面与 sharp 市场形成稳定反向；
- 隐分布：1X2 表面平稳，但让球/大小/成交/离散出现两类以上同步隐藏偏移；
- 均衡分布：前两结果概率接近、0/±0.25 常见、平局/走盘权重高。

“实/诱/阻/韬”仅作为市场结构标签，不推断庄家主观心理。

### S — Statistical / 数理统计层

核心子模型：
1. Dynamic Dixon–Coles：球队攻防、主场优势、时间衰减，重点修正 0:0、1:0、0:1、1:1。
2. 双泊松 / Bivariate Poisson：生成 0–7 球比分矩阵及尾部。
3. 负二项备选：高波动联赛或过度离散时与泊松比较。
4. Skellam：净胜球与让球方向的独立校验。
5. xG/xGA：射门质量、禁区触球、定位球、PPDA 等映射到攻防强度。
6. Elo/Glicko：球队相对实力与赛程强度的先验。
7. 市场反推 λ：同时用去水 1X2、让球、大小球拟合 λ_home_market / λ_away_market。
8. ZeroGoal：对零进球概率和低比分结构单独建模，避免高估 1:1/2:1 模板。
9. Margin：净胜球分布、让球覆盖和一球差风险。

基本方程示意：

log λ_home = μ_league + home_advantage + attack_home - defence_away + βX
log λ_away = μ_league + attack_away - defence_home + βX

输出统一来自比分矩阵：
- 1X2；
- 亚洲盘口赢/走/输；
- 大小球；
- 总进球区间；
- 单双；
- BTTS / 双方零球；
- Top2–4 比分及覆盖率；
- 半全场（由半场 λ 单独校准）。

### F — Fundamentals / 基本面与信息层

- 主客场拆分；
- 排名和真实实力定位；
- 近期状态但做对手强度修正；
- 伤停、预计首发、确认首发；
- 休息天数、旅行距离、时差；
- 天气、场地、裁判；
- 杯赛轮换、两回合总比分；
- 争冠、保级、晋级、无欲无求等战意；
- 红牌/极端比分样本降权。

F 层主要修正 λ 和不确定性，不允许凭叙事直接把概率大幅手调。

### Z — Zhouyi / 术数与随机盘影子层

首批独立实验：
- 六爻；
- 梅花易数；
- 大六壬；
- 奇门遁甲；
- 金口诀；
- 策轨数 / 周易数 / 太玄数；
- 河洛数；
- 兵法奇门 / 飞宫小奇门；
- 小成图；
- 灵棋经；
- 地占术；
- 神易数；
- 范围数；
- 响马卦；
- 清华简筮法等已存在实验模块。

硬规则：
- 一场比赛每个术数只有一个预注册版本；
- 起局时间、取数来源、主客/上下盘定义、用神、映射规则必须在赛前锁定；
- 不能赛后改用另一门派规则；
- 同类方法不能因为“多数表决”自动获得更高权重，避免重复计权；
- 随机盘保存 256-bit seed，采用可复演的独立随机流；
- Z 初始权重 = 0，仅记录命中率、Brier 增量、LogLoss 增量和与 M/S 层的交互；
- 单方法 ≥100 场只做初评，滚动样本 ≥500 且样本外稳定，才讨论进入主模型，且初始上限 3%。

### C — Calibration / 合参与校准风控层

不使用永久固定权重。采用 walk-forward 学习 stacking / calibration 权重。

冷启动可用于对照而不是定论：
- 主流联赛：市场 50%，统计 35%，信息 10%，外部共识 5%；
- 小联赛/数据稀缺：市场 65%，统计 25%，信息 10%；
- 杯赛/国家队/次回合：市场 55%，统计 25%，信息 20%。

Z 层不进入冷启动主权重。

置信度由四项构成：
- 历史校准；
- 子模型一致性；
- 数据完整度；
- 市场流动性与跨公司一致性。

自动弃权/观察条件：
- 赛程身份或时区冲突；
- 核心盘口缺失；
- 低流动性；
- 友谊赛大轮换；
- 临场首发缺失；
- 赛季初小样本；
- 单家公司独立异动；
- 开赛前 10 分钟突发反向变盘且无法解释。

## 3. 每场盲测数据结构

每场必须保存：
- match_id = competition | season | kickoff_utc | home | away
- freeze_time
- model_version
- 输入数据快照及来源
- M/S/F/Z 每个子模型的独立输出
- 主模型最终概率
- 唯一方向 + Top 候选
- 是否弃权
- 赛后真实比分
- 评价指标
- 错误分类

禁止把比赛结果写入赛前特征。

## 4. 统一评分

1X2：Accuracy + Brier + LogLoss + Calibration curve
大小球：命中率 + Brier/LogLoss + closing-line comparison
让球：覆盖率 + 走盘拆分 + 概率校准
总进球：MAE + 分段覆盖率
单双：Accuracy + Brier
比分：Exact hit + Top3 coverage + score-matrix log probability
半全场：方向命中 + 低比分/后程进球识别

模型比较不只看命中率：重点比较相对“去水市场概率”是否真正有样本外增量。

## 5. 盲测与迭代协议

### Phase A — 冻结基线
- 固定 M0 市场基线；
- 固定 S0 Dixon–Coles / Poisson 基线；
- Z 层全部影子运行。

### Phase B — Walk-forward
按日期向前滚动，不随机打乱赛季。
每个版本只有未来样本可作为真实 OOS。

### Phase C — Ablation
依次测试：
- M only
- S only
- M+S
- M+S+F
- M+S+F+M-path
- 每个 Z 单独加入

如果加入某模块后 OOS Brier / LogLoss 没改善，则不因个别命中保留权重。

### Phase D — 分层诊断
至少按以下维度切片：
- 联赛；
- 主流/小联赛；
- 热门/均势/冷门；
- 盘口深度；
- 总进球线；
- 杯赛/联赛；
- 有无确认首发；
- 顺/逆/隐/均衡；
- 临场稳定/剧烈变盘。

## 6. 单场标准输出

1. 比赛身份与冻结时间
2. 数据完整度
3. 实力/战意/阵容
4. 澳门、香港马会、12BET、立博、重点公司及百家平均初赔→即时→临场
5. 去水概率
6. 亚盘/大小球路径与欧亚关系
7. M/S/F 概率
8. 顺/逆/隐/均衡
9. 实/诱/阻/韬标签
10. 唯一 1X2 方向
11. 让球方向
12. 大小球 + 总进球区间
13. 单双 + 小单/小双/大单/大双
14. Top3 比分 + 唯一比分
15. 半全场
16. Z 影子层独立结果
17. 信度、模型分歧、冷门风险、是否弃权
18. 赛后复盘入口
