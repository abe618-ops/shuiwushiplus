# 雷公式足球盲测 Android

一个用于传统术数模型研究、赛前盲测和复盘记录的 Android 工具。项目把本轮研究中已经明确、已经冻结的规则固化为代码，避免赛后临时改盘。

> 仅供文化研究与娱乐测试。传统术数没有可靠科学证据证明能够稳定预测足球结果，本项目不构成投注建议。

## v0.1 已实现

- 正时背景盘：固定使用 Asia/Shanghai（UTC+8）当前时间。
- 完全随机盘：每次从 1900-01-01 至 2099-12-31 均匀随机抽取一天和一分钟，只抽一次、不因盘面重抽。
- 四柱：使用 `cn.6tail:lunar:1.7.7` 按节气口径获取八字，避免春节/立春边界的手工误差。
- 雷霆曜气十二星：使用校勘后的日支映射；时层按“日干起星入中，依时支所纳宫顺飞”。
- 直符：按六十甲子序数走九宫飞序。
- 传音：按寅起艮、逆九宫的可复现算法计算。
- 中宫箭：甲己巳戌、乙庚辰酉、丙辛卯申、丁壬未寅、戊癸午亥。
- 八刻微盘：每个两小时辰分为 8 个 15 分钟段，依次映射乾兑艮离坎坤震巽；这是项目实验扩展，不冒充古籍原法。
- 三种主客定位模式：
  - M1：日星=主、时星=客（旧模型对照）
  - M2：时星=主、日星=客（反向实验）
  - 双模型保守合参（默认）
- V2.3 复盘修正：
  - 正时盘降为背景层，避免密集比赛同一时辰重复盘过度支配结果。
  - 随机盘作为主要区分盘。
  - “克”可提供方向信号；“生”只视为流向/主动性，不再机械解释为受生方获胜。
  - 中宫箭只提升变局/事件权重，不再等同于必破平。
  - 正时完全同星/同五行时显著提高平局和低比分权重。
- 输出：胜平负排序、不败方向、总进球、大小、单双、半全场、3 个候选比分、结构与证据链。
- 冻结记录：保存正时/随机时间、两张盘的封盘码和赛前结论。
- 赛果复盘：录入实际比分后自动统计第一方向、候选比分覆盖、大小、单双命中率。

## 当前保留但不计权的模块

### 雷霆四箭

现存资料对简化日期口诀存在异文。本项目 v0.1 不把不确定口诀伪装成确定算法，因此界面保留“四箭”模块位，但暂不加入胜负评分。后续应以同一底本逐条校勘年箭→月箭→日箭→时箭及“有气/无气”规则，再启用。

### 白虎大杀 / 箭运式副盘

已列入后续版本计划，但在规则未完全固化前不参与评分，避免赛后解释型加权。

## 版本原则

1. 每场随机盘只抽一次。
2. 预测先冻结，再录入赛果。
3. 历史失败不回写成“命中”。
4. 参数修改只从下一场生效。
5. 主客定位仍处于盲测阶段，因此 M1/M2 必须保留独立统计，不允许赛后选择更有利的一套解释。
