# 测字演禽足球 V1

一个用于传统测字/拆字、二十八宿演禽与周易数理长期盲测的 Android 实验工具。软件不联网，起盘时从 7000 个筛选后的规范汉字中随机抽取一个字，以固定算法输出胜平负、半全场、进球数、比分、大小 2.5、单双及大小单双组合。

## 字库

构建时使用：

- `lqfeng/ChineseCharacters`：`通用规范汉字表(2013)全部(8105字).txt`，作为规范汉字顺序底表。
- `mapull/chinese-dictionary`：补充真实笔画数、部首、结构、常用等级。该项目 README 说明数据参考《通用规范汉字表》。

构建脚本按《通用规范汉字表》原顺序扫描 8105 字，过滤无法取得可靠元数据的字、Unicode 补充平面字形以及 20 画以上的复杂字，再取前 7000 个合格字生成 `char_meta.tsv` 并打入 APK。当前构建实测共跳过缺元数据 31 字、20 画以上 67 字、非 BMP 字形 77 字，最终第 7000 个候选对应原表序号 7175。运行时完全离线。

随机模式用 `SecureRandom` 生成 64 位种子，再以种子确定汉字；最近 64 次随机起字做防重复。按种子复现不使用防重复逻辑，因此同一种子必然得到同一字。

## 冻结算法 V1

1. **字形拆分**：把汉字按 Android 字体渲染为位图，统计左右、上下及四象限墨量。左作主、右作客，上部辅助半场。
2. **五行数**：左右部数映射河图数（1/6 水、2/7 火、3/8 木、4/9 金、5/10 土），按生克给主客票。
3. **拆字演禽实验层**：把左右字形数映射到二十八宿，以宿的五行比较主客；日宿按火、月宿按水是本项目为了统一五行比较而设的实验映射，不宣称是古籍唯一规则。
4. **周易层**：以上下字形数取八卦，笔画/字序/字形数定动爻，按八卦五行比较主客。
5. **胜平负**：四路票相加，达到阈值才判主胜/客胜，否则判平/胶着。
6. **半全场**：半场使用上半字形主客与上部五行；全场使用四路总势。
7. **进球数**：笔画、字形、五行、演禽、周易各投 0–6 球，取五票中位数；外应只对节奏作 ±1 球调整。
8. **比分**：先冻结胜平负，再在 0–6 球总进球内分配主客进球，保证方向与总进球数学一致。
9. **大小单双**：3 球及以上为“大 2.5”，0–2 球为“小 2.5”；总进球奇偶给单/双，并组合为大单、大双、小单、小双。

每盘保存 64 位种子与短 SHA-256 密封哈希，便于赛前冻结、赛后核对。

## 研究来源与边界

古籍《测字秘牒》记录了装头、接脚、穿心、包笼、破解、添笔、减笔、对关、摘字、观梅等测字法，并强调上下左右、外界影响与拆字取象。现代公开视频也有拆字/测字和二十八宿的通俗讲解。`kentang2017/yanqin_studies` 是可参考的现代开源演禽实现，包含“主客竞赛”概念。

本应用把这些传统材料转换成可重复的数字算法，用于文化研究与盲测。传统术数没有经现代科学证实，本软件不构成投注建议；程序中的足球映射、日月宿五行简化、0–6 球投票均属于本项目的现代实验设计。
