# 科目内容包

本目录将五个考试科目拆成彼此独立、但能够共享学习引擎和题目引擎的内容包。

## 1. 税法（一） `tax-law-1/`
重点建设税收基础规则、增值税、消费税及其他相关税种的知识点树、公式、税率/期限、规则—例外结构、计算题和综合题。

## 2. 税法（二） `tax-law-2/`
重点建设企业所得税、个人所得税及其他相关税种的知识图谱、扣除规则、优惠条件、计算流程和跨章节材料题。

## 3. 涉税服务实务 `tax-service-practice/`
突出执行型学习：申报、审核、代理、涉税事项处理、材料分析和跨税种实务。

## 4. 财务与会计 `finance-accounting/`
突出公式、计算链、会计处理、财务分析和高频易错点，并与税法计算题建立前置知识关系。

## 5. 涉税服务相关法律 `tax-related-law/`
突出概念边界、构成要件、程序、期限、主体关系和相似法律规则的交错辨析。

## 每个科目的推荐目录

```text
<subject>/
├─ syllabus.md
├─ knowledge-tree.json
├─ formulas.md
├─ memory-facts.md
├─ common-confusions.md
├─ questions/
│  ├─ verified/
│  ├─ simulations/
│  └─ variants/
└─ sources/
   └─ official-sources.md
```

## 原则

- 科目内容与学习算法解耦；
- 每个知识点具有稳定 ID；
- 每条时效性规则必须记录政策版本；
- 每道题尽可能链接到知识点和法律依据；
- 同一知识点可以通过记忆、理解、计算、材料分析、口述解释等不同方式训练；
- 未来可以按同样格式添加注册会计师等其他考试内容包。
